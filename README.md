# CustomizedPrintHub store

Static one-page store (no build step). Everything is in `index.html`.

## Deploy on Render (free)
1. Create a new GitHub repo and upload these files (`index.html`, `render.yaml`, `README.md`, `.gitignore`).
2. On render.com: **New +** > **Static Site** > connect the repo.
3. Build command: leave empty. Publish directory: `.`
   (Or choose **New +** > **Blueprint** and Render reads `render.yaml`.)
4. Click **Create Static Site**. You get a public link like `https://customizedprinthub.onrender.com`.
